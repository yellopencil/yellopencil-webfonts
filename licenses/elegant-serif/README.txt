또렷한 획과 우아한 인상을 담아 그린 세리프 활자입니다.
큰 제목부터 긴 본문까지 두루 어울리는 2종 굵기를 담았습니다.

폴더에 포함된 파일

  • TTF 폴더     글꼴 파일 (윈도우·맥·한글·MS오피스·어도비 모두 지원)
  • LICENSE.txt   라이선스 안내
  • README.txt    이 파일

설치 방법

  ▸ macOS
    글꼴 파일을 더블 클릭 → "설치" 클릭
    또는 파일들을 Font Book(서체 관리자)에 드래그

  ▸ Windows
    글꼴 파일 우클릭 → "설치" 클릭
    또는 파일들을 C:\Windows\Fonts 에 복사

  ▸ 한글(한컴오피스)에서 글꼴이 목록에 안 보이면
    한글을 완전히 종료했다가 다시 켜 보세요.
    이전에 같은 폰트의 다른 버전을 설치한 적이 있다면,
    제어판에서 제거 → 재부팅 → 다시 설치하면 해결돼요.

시작하기 전에

  우아한세리프는 SIL 오픈 폰트 라이선스(OFL) 1.1로 배포됩니다.
  개인·상업 구분 없이 자유롭게 사용·수정·재배포할 수 있어요.

  • 딱 하나, 폰트 파일 자체를 그대로 판매하는 것만 금지예요.
  • 수정하거나 다른 소프트웨어에 넣어 재배포할 땐
    LICENSE.txt(라이선스 전문)를 함께 포함해 주세요.
  • 수정·파생본에는 원본 이름(우아한세리프 / GraceSerif)을
    쓸 수 없어요. 다른 이름을 붙여 주세요.

  자세한 내용은 LICENSE.txt 파일을 참고해 주세요.

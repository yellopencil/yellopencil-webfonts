# Yellopencil Webfonts

옐로펜슬에서 제공하는 아임웹용 웹폰트 파일과 CSS를 관리하는 공개 저장소입니다.

## 카페24 아네모네

- 폰트 제작 및 저작권: 카페24(주)
- 공식 다운로드: https://fonts.cafe24.com/
- 라이선스: SIL Open Font License 1.1
- 제공 두께: 400
- 원본 라이선스: `licenses/cafe24-anemone/License-Ohsquare.pdf`

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/yellopencil/yellopencil-webfonts@v1.0.0/fonts/cafe24-anemone/font.css">
```

또는 `fonts/cafe24-anemone/font.css`의 `@font-face` 코드를 아임웹 코드 위젯에 직접 넣어 사용할 수 있습니다.

## 우아한세리프

- 폰트 제작 및 저작권: 이희배, Pear Type Foundry
- 공식 다운로드: https://peartype.kr/#font-grace
- 라이선스: SIL Open Font License 1.1
- 제공 두께: 400, 700
- 원본 라이선스: `licenses/elegant-serif/LICENSE.txt`
- 배포 형식: 제작자가 제공한 원본 TTF

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/yellopencil/yellopencil-webfonts@v1.1.0/fonts/elegant-serif/font.css">
```

웹폰트 파일은 원본 이름과 내용을 변경하지 않고 배포합니다.

## 그리운 경찰감성체

- 폰트명: 그리운 경찰감성체 (Griun PolSensibility)
- 공식 배포처: https://www.griun.co.kr/fonts/polsensibility
- 사용범위: 모든 사용 범위에서 자유롭게 사용 가능
- 제한사항: 폰트 파일 개작, 수정, 판매 금지
- 제공 두께: 400
- 라이선스 안내: `licenses/nostalgic-police-vibe/LICENSE.txt`

```html

```

웹폰트 파일은 변환하거나 수정하지 않고 원본 그대로 배포합니다.

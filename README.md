# Yellopencil Webfonts

옐로펜슬에서 제공하는 아임웹용 웹폰트 파일과 CSS를 관리하는 공개 저장소입니다.

## 카페24 아네모네

- 폰트 제작 및 저작권: 카페24(주)
- 공식 다운로드: https://fonts.cafe24.com/
- 라이선스: SIL Open Font License 1.1
- 제공 두께: 400
- 원본 라이선스: `licenses/cafe24-anemone/License-Ohsquare.pdf`

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/yellopencil/yellopencil-webfonts@v1.0.0/fonts/cafe24-anemone/font.css">
```

또는 `fonts/cafe24-anemone/font.css`의 `@font-face` 코드를 아임웹 코드 위젯에 직접 넣어 사용할 수 있습니다.
